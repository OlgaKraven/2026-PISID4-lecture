# ПиДИС · 4 курс

Интерактивные лекции по МДК.05.01 «Проектирование и дизайн информационных систем» для 7 семестра и подготовки к демонстрационному экзамену.

- 5 лекционных тем;
- 85 экранов в каждой теме: титульный лист, тема семестра, литература, QR-код материалов, учебный блок, задания, тесты и вопросы от аудитории;
- реалистичный сквозной кейс Field Service;
- настраиваемые ФИО, должность и кафедра / лаборатория преподавателя с сохранением в браузере и переносом в PDF;
- студенческая и преподавательская печатные версии;
- адаптивный интерфейс, содержание с прокруткой, клавиатурная навигация и полноэкранный режим.

## Локальный запуск

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 4174
```

## Проверка и сборка

```bash
npm run lint
npm run spellcheck
npm run test:smoke
npm run build
```

Статическая сборка для GitHub Pages:

```bash
GITHUB_PAGES=true NEXT_PUBLIC_BASE_PATH=/2026-PISID4-lecture npm run build:pages
```

PDF одной темы или всего курса:

```bash
npm run export:pdf -- --topic 01-project-decisions
npm run export:pdf
```

Файлы сохраняются в `outputs/pdf/student` и `outputs/pdf/teacher`.

## Публикация

Workflow `.github/workflows/pages.yml` собирает `dist/client` и публикует сайт через GitHub Pages при отправке изменений в `main` или ручном запуске.

## Запуск и проверка

Node.js 24 рекомендуется; зависимости зафиксированы package-lock.json.

```sh
npm ci
npm run lint
node scripts/check-methodology.mjs
npm run check:readiness -- --strict
npm run build
npm run preview -- --port 4174
```

Открыть http://127.0.0.1:4174/2026-PISID4-lecture/ . В другом терминале: `npm run test:smoke`, `node scripts/render-audit.mjs`, `npm run export:pdf`. Для Chromium при необходимости: `npx playwright install chromium`; в Windows предусмотрен резервный запуск установленного Edge.

PDF создаются в outputs/pdf/student: один слайд на страницу, без заметок и ответов преподавателя. Экспорт использует печатный режим того же движка. `SITE_URL` позволяет проверять другой сервер. Для корневого размещения задайте `BASE_PATH=/` при сборке. Открывать index.html как file:// не следует.

## Заметки преподавателя

Полный пакет public/teacher-pack.json содержит 451 заметку и по запросу владельца опубликован вместе с сайтом. При запуске заметки подключаются автоматически; ручной импорт не требуется. Каталог private с редактируемыми источниками и данными входа остаётся вне Git.

- private/teacher-source.json — редактируемый источник заметок со стабильными ID и отпечатком слайда.
- public/teacher-pack.json — пакет для автоматического подключения; после изменения приватного источника обновляйте эту публичную копию.
- private/teacher.md — полный сценарий для чтения и подготовки.
- private/preparation-cards.json — карточки подготовки по лекциям.
- private/editor-access.json — отдельные данные входа в редактор, не публиковать.

Меняйте заметки сразу при изменении соответствующего объяснения. `npm run generate:content -- --teacher` сохраняет существующие заметки. Если содержание слайда изменилось, генератор останавливается: сначала согласуйте его заметку и contentHash в private/teacher-source.json. Это защита от молчаливой перезаписи. После импорта и правок в браузере экспортируйте заметки и перенесите правки в приватный источник; хранилище браузера не обновляет файлы Git автоматически.

Проверка приватного комплекта: `npm run check:readiness -- --strict --teacher=private/teacher-pack.json`. После сборки: `npm run check:privacy`. `node scripts/check-resources.mjs` дополнительно проверяет QR, локальный шрифт, вход/черновик редактора и офлайн; для проверки входа нужен private/editor-access.json.

Вход в редактор ограничивает интерфейс локального черновика, но не является серверной авторизацией. Ключи учебной автономной самопроверки доступны в assessment.json. Полные преподавательские сценарии туда не включены.

## Авторские источники и движок

authoring/source-course.json хранит исходные данные; units.mjs — предметные разборы 20 вопросов; exam2027.mjs — привязки и примеры ДЭ 2027; scripts/generate-content.mjs собирает course.json, assessment.json и карты соответствия. После изменения источников выполняйте генерацию, проверку и сборку. Изменения из браузерного редактора перед повторной генерацией нужно согласовать с авторскими источниками.

Пакет vendor/olgakraven-lecture-engine-0.2.0.tgz собран из коммита dd0a0dc09e10916e3c07157677f7a1769396a110. npm ci использует именно этот архив. Код общего плеера и стили не скопированы в src курса. Старые app/components/hooks/lib оставлены как исторический источник миграции и не входят в новую сборку; их команды из старого README больше не применяются.

GitHub Actions проверяет и собирает dist, затем публикует GitHub Pages при обновлении main. Публичный артефакт не включает private. Подготовленный офлайн-режим сохраняет сайт на устройстве; внешние материалы Яндекс Диска автоматически не скачиваются.

## Границы покрытия

РПД и официальные часы группы не заданы. Оценки сценария около двух часов на тему не означают утверждённую длительность пары. Курс охватывает проектирование и дизайн; задания ДЭ 2–3 и полная реализация API требуют практических занятий. Field Service — учебный пример, а не предметная область приложений ДЭ. Подробнее: docs/SOURCE_AUDIT.md, docs/EXAM_2027.md, docs/QUALITY.md и reports/migration-map.json.


## Автоматическое подключение сценария

public/teacher-pack.json — опубликованный полный пакет заметок. src/startup-notes.ts загружает его при запуске, проверяет версию и добавляет отсутствующие заметки, сохраняя локальные правки. Ручной импорт исходного пакета больше не требуется. Это явное изменение прежнего режима приватной поставки по запросу владельца.

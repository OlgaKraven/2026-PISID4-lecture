# Разработка курса ПиДИС, 4 курс

Node.js 24; установка — `npm ci`. README содержит только ссылки на лабораторные седьмого семестра.

## Авторские источники

- `authoring/source-course.json` — темы, понятия и исходные примеры.
- `authoring/units.mjs` — разборы двадцати вопросов; `exam2027.mjs` — отдельные условия ДЭ 2027.
- `authoring/revision.mjs` — определения, уточнения схем и речь преподавателя по роли текущего экрана.
- `authoring/practice.mjs` — двадцать самостоятельных случаев с другими исходными данными, двумя результатами, разбором и границей вывода.

`npm run generate:content` обновляет курс, банк самопроверки, опубликованный пакет преподавателя и реестры. Базовый текст меняют в авторских источниках, личные заметки — в панели преподавателя. До обновления исходника согласуйте полезные местные правки; генерация не читает браузерное хранилище.

## Проверки и сборка

```sh
npm run generate:content
npm run check:generated
npm run lint
npm run check:methodology
npm run check:readiness -- --strict --teacher=public/teacher-pack.json
npm run build
npm run check:privacy
npm run preview -- --port 4174
```

При запущенном preview выполните `npm run test:smoke`, `npm run test:cases`, `npm run test:tasks`, `npm run test:presentation`, `node scripts/render-audit.mjs`, `node scripts/check-resources.mjs`. Другой адрес задаётся в `SITE_URL`. Утилиты используют Chromium с резервным запуском установленного Edge. Эти проверки не подтверждают апробацию с группой.

`npm run export:teaching` создаёт пять комплектов текста, сценария, заметок и карт соответствия в `docs/teaching/`. `npm run export:pdf` создаёт пять PDF слайдов 16:9 в игнорируемом `outputs/pdf/student/`. Документальные поля А4 к слайдам не применяются. Проверяйте отрисованный PDF, а не только число страниц.

## Интерфейс и движок

Зафиксирован исходный архив движка 0.2.0; расширение проверки числа вариантов воспроизводится `node scripts/prepare-engine.mjs`. Исходный архив сохраняется. Vite-плагины применяют проверяемые преобразования к точным сигнатурам движка: при несовпадении сборка останавливается. Оформление каталога и презентации находится в `src/`; код не зависит от локального соседнего проекта.

Редактор курса, тур, учебные отметки и общие кнопки повторения анимации исключены из интерфейса. Самостоятельный случай открывается из своего паспорта в отдельной вкладке и возвращает к исходному слайду. Схемы объяснения остаются на прежних местах. В двух окнах синхронизируются текущий слайд, указка, схема, публичное состояние самопроверки и тема.

## Заметки и автономная работа

`public/teacher-pack.json` опубликован по ранее принятому решению владельца. Окна аудитории и печати его не запрашивают. Ключи автономной самопроверки и самостоятельных случаев технически доступны посетителю; это учебная проверка, а не экзаменационная защита.

Исходные заметки доступны без записи всего пакета в localStorage. Сохраняются только личные изменения. При переходе с прежней редакции старые автоматические поля распознаются по SHA-256 из `authoring/baseline-note-hashes.json`; личные поля переносятся поверх новых исходных, старое хранилище остаётся нетронутым. Перед переносом на другое устройство экспортируйте личные записи из панели.

Подготовка офлайн-копии кэширует файлы сайта; материалы внешнего диска автоматически не скачиваются. При наличии сети используются свежие файлы, подготовленная копия служит резервом. GitHub Actions проверяет и публикует main через существующий GitHub Pages workflow.
